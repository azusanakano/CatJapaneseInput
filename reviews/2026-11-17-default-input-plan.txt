既定の日本語入力設定 — 2026-11-17

依頼: インストール時に CatJapaneseInput をデフォルトの日本語入力にする。
実装判断: MSI の既存 EnableTipProfile commit action (Impersonate=yes) を使う。
InstallLayoutOrTip の ILOT_DEFPROFILE で、インストールを実行した利用者の
CatJapaneseInput プロファイルを有効化し既定にする。新規と major upgrade
で実行し、repair と uninstall では既定設定を変更しない。
サービスアカウントとアカウント判定失敗時はユーザー設定を変更しない。
Windows API の失敗は MSI ログに残すが、ファイルインストールの成功を覆さない。

比較した方式: SYSTEM の RegisterTIP から設定すると対象利用者が異なる。
別 PowerShell 起動は追加依存と引用処理が必要。既存 input.dll 呼出しが最小。
インストール済みPCへの設定変更やMSIの実行は、このコード変更には含めない。
